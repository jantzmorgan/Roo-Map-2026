How It Works

Roo Map Guide

ℹ️ Instructions Tap the ℹ️ anytime for map controls, GPS help, saved spots, backups, install steps, and offline notes.
🗺️ Map Switch between Centeroo and Outeroo, pinch to zoom, drag to move, and tap stage/plaza names to open details.
👀 Hide UI Tap Hide UI when you want the clearest map view. The map usually feels smoother if you drag and zoom with slower, steady gestures instead of fast flicks.
🔵 Blue Dot The blue dot only appears after GPS is on and this map has at least 3 saved anchors. It shows your approximate spot, but it will not be perfectly exact.
📍 Save Spots Hold on any map spot, bathroom, meetup spot, camp spot, or landmark to save a custom spot. For a stage or tent, tap it first, then tap Save Spot.
⭐ Planner Mark shows as Must, Maybe, or Skip. Planner organizes your choices by day and decision.
🕒 Timeline Timeline turns your Must and Maybe picks into a clean day-by-day order with artist, location, pick type, and open gaps between events.
🔎 Search Search artists, stages, plazas, camps, and saved spots fast.
🎯 GPS Anchor Only save a GPS anchor when you are physically standing at that exact map spot. Save 3 anchors on a map before expecting the blue dot to line up.
🧭 Compass Choose a saved spot and the compass points you toward it. GPS works best after you save GPS anchors at known locations.
📶 Offline First Works offline after first load. Open the app once with good service before Roo so the map and schedule can save.
💾 Backup After planning, go to Settings → Export Backup. That saves your picks, saved spots, settings, and GPS anchors to a JSON file.
📥 Import Backup To restore a backup, go to Settings → Import Backup and choose the Roo Map JSON file you exported earlier.
📱 Install on iPhone Tap Share → Add to Home Screen.
